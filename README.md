# Chirasin Chuenthed CV

A responsive, single-page CV website with a downloadable PDF.

## Local preview

Run `python3 -m http.server 8765 --directory dist`, then visit http://localhost:8765.

## Deployment

Import this repository into Vercel. It is a static site with no build step and `dist` as the output directory, configured in `vercel.json`.

Website content is in `dist/index.html`.
